# Project instructions

## Git workflow

- Perform all Git operations through the terminal with native Git commands, including status, diff, add, commit, fetch, pull, push, and branch management.
- Do not open GitHub Desktop or use Computer Use or other GUI automation for Git operations.
- If terminal access or Git authentication is unavailable, report the blocker and stop the affected Git operation.
- Never run destructive Git commands without the user's explicit approval.
- Keep the workflow efficient and avoid unnecessary tool calls.

## Language

Write project documentation, code comments, Git commit messages, and technical specifications in English unless explicitly instructed otherwise.
