# Third-Party Resources

The Swift package has no third-party package dependencies and includes no vendored third-party library code.

The app uses Apple frameworks, system fonts and SF Symbols supplied by macOS. These system resources are subject to Apple's terms and are not relicensed by this project's Unlicense. The application icon is generated by the project's original AppKit drawing script in `tools/make-icon.swift`.

The implementation uses Yamaha protocol facts and device replies. Yamaha manuals are linked for reference and are not distributed with this project. Yamaha and its product names remain the property of their respective owners.

The Smart Pianist property identifiers and framing were researched using [ConPianist's protocol definitions](https://github.com/hugbug/conpianist/blob/develop/Source/Piano/PianoMessage.cpp). ConPianist is a separately licensed GPL project. Its source code is not bundled or linked into this utility. This project independently implements the protocol in Swift and retains the research reference.
